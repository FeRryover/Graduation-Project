# MixSimGPT 交互前端

这是一个基于 FastAPI + 原生 HTML/CSS/JS 的前端页面，用来直接调用项目中的四个核心能力。

## 功能

- 简单路网生成
- OSM 路网抓取
- 手绘图识别
- 卫星图道路提取

## 启动

在项目根目录执行：

```powershell
python -m uvicorn frontend.main:app --host 127.0.0.1 --port 8000
```

然后打开：

- http://127.0.0.1:8000

## 说明

- 该前端直接调用现有 Python 能力函数，不修改你原有算法代码。
- 图片输入目前使用本地路径字符串方式（例如 `./resources/...`）。
- 部分能力计算量较大（尤其卫星图提取），执行可能较慢。
